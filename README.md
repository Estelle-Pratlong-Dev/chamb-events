# Chamb Events

Site WordPress destiné à présenter une activité de location de structures gonflables et d'animations événementielles.

> Projet personnel — non finalisé

## Le projet

Chamb Events a été conçu pour présenter une activité familiale liée à l'événementiel et à la fête foraine, notamment la location de structures gonflables.

L'objectif était de disposer d'un site vitrine permettant de présenter l'activité, les différentes structures disponibles et les informations utiles aux clients.

Le projet a été développé sous WordPress mais n'a finalement pas été mené jusqu'à sa mise en production, notamment faute de contenus et de photographies suffisamment adaptés pour finaliser le site.

## Objectifs du projet

* Présenter l'activité et les prestations proposées
* Mettre en valeur les différentes structures disponibles
* Proposer une navigation simple et adaptée aux différents supports
* Permettre une gestion du contenu depuis WordPress
* Disposer d'une base pouvant évoluer avec l'activité
